# User Guides — Wholesale POS

Quick-start guides for every role in a wholesale shop.

| Guide | Audience | What you'll learn |
| ------- | ---------- | ------------------- |
| [Getting Started](getting-started.md) | Everyone | Install, activate your license, set up your first owner account |
| [Owner Guide](owner-guide.md) | Shop owners | Manage users, view reports, configure sync, handle licensing |
| [Cashier Guide](cashier-guide.md) | Cashiers / till operators | Process sales, manage shifts, void requests, quick reference |
| [Finance Guide](finance-guide.md) | Finance staff | Record income/expenses, manage categories, reconcile entries |
| [Warehouse Guide](warehouse-guide.md) | Warehouse staff | Receive purchase orders, pick stock, manage customers/suppliers |
| [Troubleshooting](troubleshooting.md) | Everyone | Common errors, offline mode, data restore, license issues |

---

## Where to Start

- **New shop**: Read Getting Started, then Owner Guide, then whichever role-specific guide you need.
- **Cashier onboarding**: Get activated by the owner, then read Cashier Guide.
- **Switching from paper/other system**: Read Troubleshooting → Data import/export section first.
